# operatorLabel

The translated label of a condition operator (`eq`, `neq`, `gt`, `gte`, `lt`, `lte`, `present`), as the editor's operator choice shows it.

```js
import { operatorLabel } from '@conduction/nextcloud-vue'

operatorLabel('gt') // "greater than"
```

See also [`operatorsForType`](./operators-for-type.md).
