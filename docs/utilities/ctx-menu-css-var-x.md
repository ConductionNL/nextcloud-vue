# CTX_MENU_CSS_VAR_X

CSS custom-property name (`--cn-ctx-menu-x`) that [`useContextMenu`](./composables/use-context-menu.md) sets on `document.documentElement` to carry the cursor X position to the rendered menu. Exported so consumers can reference the same variable in custom styles.

```js
import { CTX_MENU_CSS_VAR_X } from '@conduction/nextcloud-vue'
```
