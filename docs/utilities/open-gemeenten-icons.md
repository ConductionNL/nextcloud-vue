# openGemeentenIcons

`openGemeentenIcons` — the **OpenGemeenten Iconenset** ("Line" style), 256
glyphs bundled as self-contained `data:image/svg+xml` URIs. Each entry is
`{ id, label, url }`. Public domain (**CC0-1.0**) — see
[`src/icons/ATTRIBUTION.md`](https://codeberg.org/Conduction/nextcloud-vue/src/branch/beta/src/icons/ATTRIBUTION.md).

```js
import { openGemeentenIcons } from '@conduction/nextcloud-vue/src/icons/openGemeenten.js'
// <CnIconBrowser :url-icons="openGemeentenIcons" … />
```

Part of [NL_DESIGN_ICON_GROUPS](./nl-design-icon-groups.md); see also
[rvoIcons](./rvo-icons.md), [denHaagIcons](./den-haag-icons.md).
