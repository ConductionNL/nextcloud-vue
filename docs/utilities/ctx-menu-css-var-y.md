# CTX_MENU_CSS_VAR_Y

CSS custom-property name (`--cn-ctx-menu-y`) that [`useContextMenu`](./composables/use-context-menu.md) sets on `document.documentElement` to carry the cursor Y position to the rendered menu. Exported so consumers can reference the same variable in custom styles.

```js
import { CTX_MENU_CSS_VAR_Y } from '@conduction/nextcloud-vue'
```
