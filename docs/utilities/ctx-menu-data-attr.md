# CTX_MENU_DATA_ATTR

Data-attribute name (`data-cn-ctx-menu`) that [`useContextMenu`](./composables/use-context-menu.md) toggles on `document.documentElement` while a context menu is open. Exported so consumers can target the open state in custom CSS.

```js
import { CTX_MENU_DATA_ATTR } from '@conduction/nextcloud-vue'
```
