# contrastWithWhite

The WCAG 2.x contrast ratio between white and a `#rrggbb` colour, from 1 to 21. The app tile tests use it to prove every palette colour keeps the white icon readable.

## Import

```js
import { contrastWithWhite } from '@conduction/nextcloud-vue'
```

## Signature

```ts
function contrastWithWhite(hex: string): number
```
