# WIDGET_PLACEHOLDER_COUNT

The range a declared placeholder `count` may take: `{ min: 1, max: 24 }`. The count is how many rows, lines, tiles or counters a placeholder draws, clipped to the widget's content area.

## Import

```js
import { WIDGET_PLACEHOLDER_COUNT } from '@conduction/nextcloud-vue'
```

See [`normalizeWidgetPlaceholder`](./normalize-widget-placeholder.md).
