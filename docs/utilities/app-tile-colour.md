# appTileColour

The [`APP_TILE_COLOURS`](./app-tile-colours.md) entry for a key, or `null` when the key is not in the palette.

## Import

```js
import { appTileColour } from '@conduction/nextcloud-vue'
```

## Signature

```ts
function appTileColour(key: string): { key: string, label: string, hex: string } | null
```
