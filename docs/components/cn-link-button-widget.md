# CnLinkButtonWidget

Link / button widget with single and list display modes; emits `internal-action`/`create-file` for host-handled actions.

Part of the dashboard widget library (v2). Registered with the dashboard widget registry and consumed by LaunchPad's widget grid. See [the widget library overview](./cn-widget-grid.md) and `docs/architecture/cards-and-widgets.md`.

An entry's `actionType` is `external`, `internal` or `createFile`. The list schema's spellings `url` and `action_id` mean `external` and `internal`, so an `action_id` entry renders as a button that emits `internal-action` with its action id instead of becoming a link. The form opens either spelling and saves the canonical one.
