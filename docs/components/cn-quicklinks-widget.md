# CnQuicklinksWidget

Icon-grid quick-links widget with configurable icon size, columns and labels.

Part of the dashboard widget library (v2). Registered with the dashboard widget registry and consumed by LaunchPad's widget grid. See [the widget library overview](./cn-widget-grid.md) and `docs/architecture/cards-and-widgets.md`.

Each link's label always stays reachable via a native `title` tooltip when it isn't fully visible in the tile itself: when `showLabels` is `false` (always), or when `labelPosition` is `below` and the label has actually been measured as ellipsis-truncated — a short `below` label that fits gets no tooltip. The `overlay` position already reveals the label on hover/focus, so no tooltip is added there.
