# CnTextWidget

Multi-line rich-text / markdown widget with optional table mode (sanitised HTML).

Part of the dashboard widget library (v2). Registered with the dashboard widget registry and consumed by LaunchPad's widget grid. See [the widget library overview](./cn-widget-grid.md) and `docs/architecture/cards-and-widgets.md`.

## Translation and a link

`content.text` goes through the app's translate function, so manifest source text reads in the user's language like the other widgets. `content.link` draws a link under the text: `{ "label": "Bekijk de afspraken", "route": "SlaAttainment" }` (a page id, or a router path starting with `/`) or `{ "label": "Docs", "href": "https://example.org" }` (opens in a new tab). The label is translated too.

```json
{ "type": "text", "title": "Afspraken", "content": { "text": "3 afspraken vandaag", "link": { "label": "Alle afspraken", "route": "Appointments" } } }
```

## Text as typed

Boards PqKassaAfrekenen and PqKassabon show a receipt: a column of plain text whose spaces line the amounts up. `content.monospace: true` shows the text in a fixed-width font, with its spaces and line breaks kept. The text is never parsed as HTML or markdown, so a `<` in it stays a `<`. Long lines wrap rather than scroll.

On a detail page, `content.textField` reads the text from that field of the page's object (the `objectData` prop, which the detail page passes) instead of `content.text`. The field's value is shown as it is, without translation.

```json
{ "type": "text", "title": "Receipt", "props": { "content": { "textField": "receiptText", "monospace": true } } }
```

An empty text shows the usual placeholder.
