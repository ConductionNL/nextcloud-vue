## ADDED Requirements

### Requirement: A facts link's icon sits beside its text in the board look

In the board look, a facts card's link that carries an icon SHALL set the icon beside its text, 10px apart, with the text on the normal line starting 10px under the card title.

#### Scenario: a work instruction
- **THEN** the book icon and "Lees hoe wij dit soort zaken behandelen" share one row
