# index-count-subtitle-keeps-crumb-row

## Why

In the board look an index page header is a grid: the title and the header buttons on row 1, the count line
(`countSubtitle` or `description`) on row 2. The breadcrumb row had no place of its own, so when a page had a count line
the breadcrumb took the next free cell: row 2 beside the count line, under the header buttons (dossiq Case types and
Cases lists, boards DqZaaktypen and DqZaken).

## What changes

In the board look the breadcrumb row of an index page stands under the title in the title's column, and a count line
follows it on the next row.
