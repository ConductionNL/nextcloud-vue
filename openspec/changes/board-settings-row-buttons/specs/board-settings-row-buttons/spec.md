# board-settings-row-buttons Delta

**Status**: proposed
**Scope**: nextcloud-vue

## ADDED Requirements

### Requirement: A button in a settings table row is 34px

In the board look a labelled button in a table cell on a settings card SHALL be 34px high with 12px inline padding;
other labelled buttons in the card body stay 40px.

#### Scenario: dossiq's ZGW mapping

- **GIVEN** the ZGW mapping table on the advanced settings tab in the board look
- **THEN** a row's "Bewerken" is 34px high and its text starts 12px in
