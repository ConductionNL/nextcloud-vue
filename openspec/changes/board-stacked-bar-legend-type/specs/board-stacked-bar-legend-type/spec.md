# board-stacked-bar-legend-type Delta

**Status**: proposed
**Scope**: nextcloud-vue

## ADDED Requirements

### Requirement: A board stacked bar legend is set in the board type

In the board look on a dashboard page, a (non-compact) stacked bar legend SHALL set its label at 14px and its count at 22px, both at the normal line height.

- **THEN** a legend item ("Ontvangen 3") is 46px high
