## ADDED Requirements

### Requirement: The reveal button reads in the main ink

A facts widget's reveal button ("Show") SHALL draw in the main ink, not the theme's button colour, as an outlined pill
30px tall.

#### Scenario: DqContact "BSN tonen"

- **WHEN** a contact's masked BSN shows with its reveal button
- **THEN** "BSN tonen" reads in the main ink on a 30px outlined pill
