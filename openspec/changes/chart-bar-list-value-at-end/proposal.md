# chart-bar-list-value-at-end

DqProcesanalyse "Doorlooptijd per status" draws bars without a track, each as long as its share, with the value 6px after the bar's end, labels in 13px secondary text, 18px bars 34px apart. The bar list drew a full-width track with the value in its own column. `barValueAtEnd` draws the board's list; the default stays.
