## Purpose

A board side card's list starts where the boards draw it.

## ADDED Requirements

### Requirement: A board side card's list starts 10px below its title

In the board look, a side card whose body opens on a record list SHALL start the list 10px below the title block.

#### Scenario: DqZaaktypeRegels "Versies"

- **WHEN** an administrator opens a case type
- **THEN** the hairline over "Versie 1" sits 10px under the "Versies" title box
