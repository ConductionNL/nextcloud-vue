### Requirement: The Learn more button keeps the main ink under a theme

CnFeaturesBoard SHALL draw a feature card's "Learn more" button in the main ink without an underline, also under a
theme that paints every link in its link colour.

- **WHEN** a user opens Functies en roadmap with the NL Design theme on
