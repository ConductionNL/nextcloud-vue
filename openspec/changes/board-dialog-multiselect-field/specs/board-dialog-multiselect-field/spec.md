## ADDED Requirements

### Requirement: a multiple select in a board dialog is the board's 40px field

In a board dialog a multiple NcSelect MUST draw its search field 40px high with the dialog's 1px field edge, and its toggle MUST NOT draw a second ring.

#### Scenario: sharing a saved view
- GIVEN the share dialog of a saved view in the board look
- THEN "Delen met" is a 40px field with a 1px edge
