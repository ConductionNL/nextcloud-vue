# board-ruled-list-card-start Delta

## ADDED Requirements

### Requirement: A board ruled list in a page card starts 12px under the title

In the board look, a page card whose content opens on a ruled rows list SHALL start the list 12px under the title, and
each row SHALL have 12px above and below its text.

#### Scenario: DqContact Zaken

- **GIVEN** Sanne de Vries with open cases
- **THEN** the first case's title is 25px under the "Zaken" title
