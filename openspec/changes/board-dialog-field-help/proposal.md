# board-dialog-field-help

## Why

In a board dialog a text field's help line drew at the body size, inset by the field's corner radius and in the
theme's body ink. The boards draw it 13px, muted and flush with the label (PtUitnodigen, PtAccountUitgeven).

## What changes

- In a board dialog the help line of a text field or text area is 13px at 1.3, in the muted ink, 4px under the
  control and flush with it.
