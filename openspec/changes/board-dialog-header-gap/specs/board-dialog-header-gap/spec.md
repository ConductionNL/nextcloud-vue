## ADDED Requirements

### Requirement: a board dialog's body starts 22px under its header

In the board look a dialog's first body block MUST start 22px under the header text, and a choice-cards legend in a board dialog MUST be 14px, weight 600, on the normal line height.

- GIVEN the generate-document dialog
- THEN "Sjabloon" stands 22px under "Een brief of beschikking uit een sjabloon..." at 14px/600
