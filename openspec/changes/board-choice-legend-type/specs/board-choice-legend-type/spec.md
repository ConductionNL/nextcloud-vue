## ADDED Requirements

### Requirement: A board dialog's choice legend is 14px/600 on the normal line height

In the board look, a CnChoiceCards legend inside a board dialog SHALL be set
at 14px, weight 600, `line-height: normal`.

#### Scenario: the template choice in Document genereren
- GIVEN the board look and the Document genereren dialog
- WHEN the template choice renders
- THEN its legend "Sjabloon" is 14px, weight 600, on the normal line height
