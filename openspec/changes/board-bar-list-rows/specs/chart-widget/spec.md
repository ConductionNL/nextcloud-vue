## ADDED Requirements

### Requirement: a board bar list stands its rows as the board draws them

In the board look a chart's bar list row MUST carry no button margin and MUST be set at 14px with the normal line height, so the rows stand 27px apart with the list's 10px gap.

#### Scenario: DqDashboard "Zaken per status"
- GIVEN the bar list of five statuses in the board look
- THEN consecutive rows stand 27px apart
