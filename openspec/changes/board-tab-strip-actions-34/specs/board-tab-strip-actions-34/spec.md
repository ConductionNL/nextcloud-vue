## ADDED Requirements

### Requirement: the tab strip's Actions button is 34px in the board look

In the board look, the labelled menu button at the end of a tab strip MUST be 34px high, and a labelled menu button in a page or card header MUST stay 40px.

#### Scenario: a case page
- GIVEN a case page in the board look
- THEN the tab strip's "Acties" is 34px and the page header's "Acties" is 40px
