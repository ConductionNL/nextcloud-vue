## ADDED Requirements

### Requirement: Board choice rows are as compact as drawn

In the board look a choice option's title and description SHALL be set at line height 1.2 with the option's icon on the
title line. A chosen option's fields SHALL start under its text when the option has an icon.

#### Scenario: Next step dialog
- **WHEN** the Next step dialog opens with Opschorten chosen
- **THEN** each idle option is about 60px high and Opschorten's fields start at the x of its title
