## ADDED Requirements

### Requirement: a board matrix starts where the card header ends

In the board look, a matrix chart on a bordered dashboard card MUST start directly under the card header, without the 4px start an HTML chart body otherwise takes.

#### Scenario: DqProcesanalyse Dagen per fase
- GIVEN the days-per-phase matrix under its title and subtitle
- THEN its column heads start 37px under the title top's line, as drawn, and the card is 758px tall
