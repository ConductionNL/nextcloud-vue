## ADDED Requirements

### Requirement: A thread header's labelled button is 40px

In the board look a labelled button in a CnConversationThread header SHALL draw at the board control height (40px). Menu triggers and icon-only buttons keep their size.

- **GIVEN** the case's Contact tab in the board look
- **THEN** "Contact vastleggen" in the thread header draws 40px tall
